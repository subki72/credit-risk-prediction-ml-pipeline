# Contributing to Credit Risk Prediction ML Pipeline

We welcome contributions adhering to production ML engineering standards.

## Local Setup

```bash
git clone https://github.com/subki72/credit-risk-prediction-ml-pipeline.git
cd credit-risk-prediction-ml-pipeline
make install
```

## Verification Gates

```bash
make lint
make test
```

## Pre-Commit Hooks

```bash
pip install pre-commit
pre-commit install
```
